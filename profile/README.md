## Built on Stellar

Settles on **Stellar** and runs its rules in **Soroban** smart contracts — transparent, inexpensive, and fast to finality.

## Overview

Built on Stellar, Augora combines XLM pools, wallet-signed transactions, and contract-enforced payout accounting so market mechanics are reviewable in code.

## Capabilities

| | |
| --- | --- |
| **Clear question, clear close** | Every market publishes its resolution criteria and close time before anyone takes a side. |
| **Buy, reduce, settle** | Participants stake XLM, may reduce a position before close, and claim proportional payouts after an authorized resolver submits the outcome. |
| **Honest about the edge** | Resolution is permissioned and there is no automated oracle — those trust assumptions are documented, not hidden. |
